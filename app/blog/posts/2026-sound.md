Since the model was running, I built some interesting things with it.

This is a project that I started in September 2026. It's a website where you speak and it plays the guitar. It's a somewhat silly idea, and it doesn't have the best latency, but it's a good example of what a fast model can do.

If you're on a laptop, you can go to [sound.sksh.io](https://sound.sksh.io) and try it out. (It will ask for microphone permissions, which I understand if you don't want to grant).
![song.png](/images/song.png)

You can also talk to a cat. Pick one from a set, and you can set its mood by talking with it.

![cat.png](/images/cat.png)

The cat only talks cat, so don't expect it to understand you if you try to reason with it.
