_A repository for big ideas_

## Ideas

This is a repo for big ideas.

Every once in a while I get an idea for a big project and I get very excited about it. Usually the idea is so big that I never actually get around to starting it. This is a repo of those ideas.

## Inspiration

This repo is inspired by two things. 

First, this video on [The Maker's Schedule](https://www.youtube.com/watch?v=o62aPBj8F6c). The Maker's Schedule is the idea that people who are creative and need to be in a state of flow in order to work productively, cannot be productive if they have to context switch often. As such, it is hard for them to easily fit meetings into their day. 

When I first got a full-time job, I was amazed at how productive I could be. I would only have meetings 1 or 2 days a week, and the rest of the time I would be able to just focus on work and get things done. I was able to design and build a project that I was working on from start to finish and so I was in a constant state of flow. After several months, the number of meetings I was going to started to increase and I noticed my productivity dropping. There were many days where I could never get into a state of flow because I had to constantly context switch between meetings, which made it very difficult to be productive. 

I realized that I couldn't fit much creative work into my schedule at that time, and I was getting frustrated. So I had to figure out a way to still build things and be productive when i can only get ~1 hour of free time a day, instead of 8 hours. I set out to find out how to be productive with small chunks of time and stumbled upon this video. 

I was inspired by the idea of the [maker's schedule](https://www.youtube.com/watch?v=o62aPBj8F6c), and the productivity tips in this video. In particular, I was inspired by the idea of a "Big List". The big list is a place to put all the big ideas you have. I liked this idea a lot. It would allow me to clear my head of the big ideas I had and allow me to focus, and it would also prevent me from forgetting about the ideas. 

The second thing that inspired me was [this video](https://www.youtube.com/watch?v=4smRXyj_meo) on building things with small chunks of time. The idea is to have a system in place for each project you have where you can pick up a project and find exactly where you left off, and continue working on it. For example, you could create a list of very specific things you want to work on, and then just start with the first item on the list, and work your way down. 

## My List

So I decided that I wanted to make my own big list of ideas. I wanted to have a list of ideas I could pick and choose from. I wanted to have a system in place where I could work on one idea for some time, and then switch to another idea and pick up exactly where I left off. I wanted to have a way to keep track of the progress I made on my ideas, and have some sort of structure for them. 

But, at the same time, I didn't want to spend a lot of time thinking about how I was going to implement this system. I wanted to spend time actually working on my ideas, not creating a system for them. So I decided to just create a GitHub repo, and use markdown files to write about my ideas, and keep track of my progress. 

This is that repo.
