My old blog was a set of handwritten pages, kept in my notes app, that I used to manually copy onto my GitHub account in a document called `Blog.md`.

Why did I do this? Because I had a problem: I was tired of forgetting every single piece of syntax and every obscure function I had for big data frameworks like Spark, Hadoop, and Hive, but I also didn't want to build a full-blown website. So I began writing in my notes app and then copying to my GitHub repo.

It was a hack. But it was actually a pretty good one.

Here's how my solution played out: I wrote in my notes app in a file called `Blog`. This file was automatically backed up to my iCloud, so I never had to worry about losing my data. This worked well, except that I wanted my notes to be public so that people could read them. I wasn't ready to build a full website yet, but I <em>could</em> post my notes to my GitHub account as a markdown file.

So I started copying the contents of my `Blog` file onto a GitHub repo I had that was called `DataScienceProblems`. I would manually copy it over and and push it to the repo, and then boom—everyone could read it.

I liked this system enough that I emailed myself a copy of the notes file on 2021-11-23 at 3:08 PM saying, "Looks like I've gotten into the habit of adding notes to my GitHub. Here's the latest one I've been working on: https://github.com/sksq96/DataScienceProblems/blob/main/Blog.md"

But now, in a very ironic twist, I've lost my blog.

I can't find my `Blog` file in iCloud anymore. I don't know when it stopped syncing or why, but I've had to start over. That's why I'm glad I copied it to my GitHub repo.

On the other hand, for some reason, I can find a copy of my 2021 `README.md` file in my Kindle notes, which I must have saved to my Kindle so that I could read it on my e-reader. I can see everything I wrote in the month of November 2021, and it's actually pretty good. I won't repost it here, but you can read it yourself on GitHub.

I also have a bookmark in my browser to a page where I was looking for a post from my blog. This tells me I lost my blog before 2024-06-08, which is when I saved that bookmark.

I have a vague memory of one of my blog posts: it was about reading research papers, and I think it was called "How to read research papers". I found the actual post on the Wayback Machine, and it's a really good one. I'll probably republish it here on my new blog one day, but I'll also add a comment from my 2026 self explaining how my thinking has changed since then.
