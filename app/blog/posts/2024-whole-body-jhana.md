*[Here's a writeup about my research into whole-body jhana, specifically what Rob Burbea calls "sukkha-body jhana".]*

## Introduction

There's a large Reddit thread with people discussing how to do it. Okay, cool.

There are 2 videos where Rob Burbea talks about whole-body entrance into jhana:

- Noting the Energy Body (39:00)
- Instructions for the Whole-body Breath

Okay, cool.

But what ... is it?

By "it", I mean *what is being described as "whole-body" in whole-body jhana?*

When I'm in jhana, I have a relaxing, pleasant feeling. It has a specific location. And it has a specific size.

It's sort of like this:

```
.---------------------.
|                     |
|                     |
|                     |
|                     |
|                     |
|                     |
|          "x"        |
|                     |
`---------------------`
```

Unless I'm in Simultaneous Access (SA), where it looks like this:

```
.---------------------.
|                     |
|        "x"          |
|     "x" "x"         |
|       "x"   "x"     |
|     "x"        "x"  |
|          "x"        |
|          "x"        |
|                     |
`---------------------`
```

Now, I'm under the impression that *whole-body* jhana feels like this:

```
.---------------------.
|*********************|
|*********************|
|*********************|
|*********************|
|*********************|
|*********************|
|*********************|
|*********************|
`---------------------`
```

So ... what's the difference between these?

## 2 interpretations

As far as I can tell, there are 2 interpretations.

1. *Whole-body jhana refers to a whole-body **object**, while it still has the 1-point **feeling***. In this case, it looks like this:

```
.---------------------.
|*********.***********|
|*********.***********|
|*********.***********|
|*********.***********|
|*********.***********|
|*********.***********|
|*********x***********|
|*********************|
`---------------------`
```

2. *Whole-body jhana refers to a whole-body **feeling***. In this case, it looks like this:

```
.---------------------.
|xxxxxxxxxxxxxxxxxxxxx|
|xxxxxxxxxxxxxxxxxxxxx|
|xxxxxxxxxxxxxxxxxxxxx|
|xxxxxxxxxxxxxxxxxxxxx|
|xxxxxxxxxxxxxxxxxxxxx|
|xxxxxxxxxxxxxxxxxxxxx|
|xxxxxxxxxxxxxxxxxxxxx|
|xxxxxxxxxxxxxxxxxxxxx|
`---------------------`
```

In the first case, you're still focusing on a 1-point object. It's just that it has a larger extent. The 1-point feeling is still there.

In the second case, you're focusing on a whole-body feeling. It has a larger extent.

Are people in the Reddit thread, and Rob Burbea, referring to one or the other? *That's what I want to know.*

## What I'm doing

For now, I'm doing the latter.

I'm maintaining the feeling across the whole body. When I start to lose the feeling in a specific area, I increase the feeling in that area. This way, I maintain the feeling across the whole body.

I'm doing it this way because in his talk on Noting the Energy Body he talks about the "whole-body breath". In his indrawn breath, he widens a pleasant feeling across the whole body. In his outdrawn breath, he relaxes the whole feeling.

So, instead of the breath, I'm staying with the whole body. I increase the pleasant feeling across the whole body, and relax it across the whole body.
