Most of my code at IIT Mandi had a very small and clear user base.

Exodia 2015 website

My first project was the website for Exodia 2015. Every year, IIT Mandi hosts a festival called Exodia, named after the final stratagem in the anime Yu-Gi-Oh. Exodia 2015 was the second edition of the festival, and I was asked to build its website.

The website was to be hosted on the IIT Mandi domain, and it listed the sponsors, dates, and other information. I built it with HTML and CSS, and used JavaScript to animate the ducks. The website was mostly static, and it was the first website I ever built. I was pretty happy with it.

SAC Website

The IIT Mandi Student Activity Center (SAC) is an organization headed by the students of the institute to handle festivals and other cultural activities. The festivals, Exodia (cultural) and Convergence (technical), were handled by different teams. The SAC was the center for all the festival teams.

The SAC needed a website to show updates and team information. I built that website next. It was also written in HTML and CSS. The website was mostly static, except for the blog posts, which were written by the SAC team.

After the website was completed, the SAC decided to create a single website for all the festivals and events at the IIT Mandi campus. To that end, I built a directory of all the teams and their websites. This was the first website I built that used a database. The directory stored the team name, people in it, and their contact information. I made this site using Python Flask and SQLite. 

Contact Book

The directory was helpful, but it was a bit ugly and not very user-friendly. I needed other people to add the team information to the database, but I couldn't ask them to use the Python Flask website. I needed a better interface.

I decided to build a frontend for the database. The frontend was written in Angular JS, and it used the same database as the directory. The frontend was much better looking, and it was much easier to use. I was very happy with it.

The frontend was a huge learning experience for me. I was able to use Angular to make the website very interactive. I learned a lot about how to use Angular, and I learned a lot about how to make a website look good. I also learned a lot about how to make a website usable.

Feedback

A few months after we launched the Angular app, someone came up to me and told me that they found it very easy to use. I was very happy to hear that. I had never received feedback like that before, and it made me feel like I had done a good job.

Feedback from Shashank Gupta:

> Hey so your contact book app is very good. It is very easy to use.

I really like that feedback. It is short, and it tells me that I did a good job. It also tells me that I should keep using Angular for my websites.
