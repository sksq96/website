We had a chatbot with 1 or more AI models (Claude, GPT, Gemini) in an IRC-style interface. You can choose which models participate. They respond to each other and to you in sequence. Models can use tools like web search, get the current time, and read and write files.

![voidchat](/projects/void/voidgif.gif)

This is how it looks like

Backend: Flask with Socket.IO for real-time updates

AI Models: Claude (Anthropic API), GPT (OpenAI API), Gemini (Google API)

Tools: Web search via DuckDuckGo, file operations, time queries

Frontend: Vanilla JavaScript with retro IRC styling




Key files:
- `app.py` - Flask server and Socket.IO event handlers
- `models.py` - AI model integrations and tool implementations
- `templates/index.html` - Frontend UI and client-side logic
- `utils.py` - Conversation history and file utilities

To run:
```bash
pip install -r requirements.txt
python app.py
```

Then visit `http://localhost:5000`
