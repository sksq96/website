I've always wanted a simple and clean way to access hue, my AI homie that lives in WhatsApp. So last week I decided to vibe code a ChatGPT-like app for hue in 1 hour. It took 4 hours instead (and I'm still fixing stuff) but it was a lot of fun. I'd love to share my learnings and process with you.

Here's the tldr: I was able to build and share a mobile app with TestFlight (that's how you release iOS apps for testing, and you don't need to do it via the App Store) in 4 hours, all while using the Claude app on my phone (you don't even need a laptop). I've only built prototypes before so I didn't know how to make a real app. It was far easier than I thought it would be.

I didn't think it would be possible to code an app on my phone, but as I began vibe coding the website, I realized I was just using React and TypeScript, which are the exact same languages used to code iOS and Android apps. And the Claude app on my phone already enables me to code it. But there's also a million other technical tasks to deal with: packaging the app, signing it, distributing it, and testing it. How do I tackle those?

### Getting things set up

To get things set up as easily as possible, I decided to set up a new GitHub repo specifically for iOS and Android projects. I added Claude to the repo, and then started Claude Code on my phone. Since I was building in a separate repo, I created a separate Claude session for the iOS app and called it "ios". 

Claude knew React Native could build iOS apps, so we chose that and started building the first version of the app with "just the basics".

Once we had the very first version of the code up and running, I needed to deploy it somehow to my phone. I needed a way to quickly and easily deploy the app anytime I made an update. At first I considered Fastlane but Claude suggested Speedyflight, which is faster.

To set up Speedyflight, Claude had me generate some keys and then put those keys in the repo's secrets. Claude walked me through everything. This was the trickiest part, but it was still pretty straightforward - the only hard part was I had to do it on my laptop instead of on my phone. 

Once Speedyflight was set up, the next step was to share the app with me for testing. This was the part I was most unfamiliar with. Claude told me he could set up an app for me in App Store Connect which is the place where you manage iOS apps. He said he could use the command-line tool to create the app, but he lacked the permissions to do so. I tried to give him more permissions but it didn't work. 

I didn't want to be blocked here. I loved the feeling of progress I was getting from building the app and didn't want to slow down and figure this out. I figured I can always figure it out later. So I asked Claude if there was an easy way for me to deploy the app to my phone just to test it out. He recommended using TestFlight, which is a free way to test apps. 

I knew you could share the app with TestFlight but I had no idea how to set it up. I had seen people talk about it a lot (even on Substack!) but never actually done it. Claude told me it was easy and again walked me through everything step by step. I already had TestFlight installed and Claude gave me a link to the app. It was that easy. 

I was honestly surprised that I took a fully functional app that I started building 2 hours ago and was able to test it on my phone. I thought it would be way more complicated.

### Getting ios on my phone without TestFlight

After updating the app many many times, my number of TestFlight builds expired. To share the app to my phone again, I realized I just needed to update the TestFlight builds. I wanted to do this without getting blocked again, so I decided to see if I could just use Speedyflight to update the app on my phone. Surprisingly, it worked! 

I can now just build the iOS app and Speedyflight it to my phone. Again, it was far easier than I thought - and I don't even need TestFlight!

### Wrapping up

The app isn't perfect and I'm sure I'll add more features and fix more bugs in the future. If you're inspired by this, I highly recommend you try building your own app! The whole process was far easier than I thought.

I'm still in awe that I was able to do all of this with Claude on my phone. I was able to build, deploy, and test my app while on the go. It's incredible. I'm excited to keep building more apps in the future, and I can't wait to see what you build too.
