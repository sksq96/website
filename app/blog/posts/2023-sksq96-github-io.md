This is part of a series of projects I did in my final year of my masters degree. Check out [my introduction post](../index.html) for more!

## Origins

In October 2023, I had the idea of making a website to showcase my work. I had already worked on a couple projects before this, but I wanted to have a platform to document all of my work and projects, both professional and personal.

This was a pretty simple project to make, and I completed it in the span of a couple days. I started this project before I began my final year project, and it still serves as my personal site.

## Design

While I'm not much of a designer, I did have some design experience with my university's [Hack+ team](../HackPlus/), which I led for 2 years. As a result, I had a decent sense of what I wanted my website to look like.

I decided to go for a minimalist design, and tried to make it as simple and clean as possible. I wanted to make sure that the content was the focus, and that the design didn't distract from it. I also didn't want to put too much effort into the design, so I tried to keep it as simple as possible.

## Website

I used GitHub Pages to host my website. I used [Jekyll](https://github.com/jekyll/jekyll) to generate the website, and used the [Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes) theme. I wanted to use [my GitHub username](https://github.com/sksq96) as my domain name, and GitHub Pages was the easiest way to do that.

I forked the Minimal Mistakes theme, and made some minor changes to it. I added a new page for my projects, and added some new links to the navigation bar. I also added a new page for my blog, and added some new links to the navigation bar. I also added a new page for my resume, and added a new link to the navigation bar.

## Conclusion

I'm pretty happy with how my website turned out. It's simple, clean, and easy to navigate. It's also easy to maintain, and I can easily add new content to it. I'm glad that I decided to make a website, and I'm glad that I decided to use GitHub Pages to host it.
