Imagine you're working on a Jupyter notebook and are stuck at an exercise. You've read the instructions, but you don't know what to do to solve the problem. What if there is a button that you could click that would show you the correct code to fill in?

That's exactly what this blog post is about.

One of the major use-cases for Jupyter notebooks is teaching and learning. The interactive nature of Jupyter notebooks lends itself well to providing an immersive learning experience for students. However, there is a gap in the interactivity- students are still constrained to follow a static set of instructions and are mostly left to their own devices.

The motivation for this project stems from wanting to use Jupyter notebooks to teach deep learning to students with little programming experience. Instead of having predefined solutions that the students can just copy, what if we could generate solutions on the fly?

### The Solution

![pandas-solution](assets/results.png)

This is the output we want to get. The other functions were generated by the GPT-3 model.

What we want is to generate the code that would allow anyone to convert a csv file to a pandas dataframe.

The key insight here is to frame the code-generation problem as a text-infilling problem. We can transform code-generation problems by providing context (the code that was already written) and a description of the problem to solve. If you're familiar with BERT or T5, you'll know that these are pre-trained language models that excel at text-infilling problems.

![nll-loss](assets/nll-loss.png)

If you want to know more about text-infilling, check out my previous blog post:
[https://sksq96.github.io/blog/text-infilling](https://sksq96.github.io/blog/text-infilling)

### Transforming the Problem

![result-infilling](assets/result-infilling.png)

The trick is to add a placeholder for where we want to fill in some code, and to describe what that code should be doing. Now we can pass the text into the language model to generate some code.

### Conclusion

The demo video above shows the code generator *in the best possible light*. In reality, the model is only able to generate code for very simple tasks, and doesn't always work when executed.

In future, I aim to finetune a text-infilling model to be better at generating python code.
