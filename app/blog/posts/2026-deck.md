it's been annoying me for a long time now that I can't find a good tweet scheduler. [draft.so](http://draft.so) is the one I use but the UI and UX is rough (I like its auto-analyses).

tried typefully for a bit but it didn't have some features that I wanted. 

I also have some other ideas about scheduling tweets, and great features that could make it stickier/more useful. So I decided to build a quick prototype.

the one thing I had in mind for sure was being able to view the tweets from the scheduler itself. I didn't want to go back and forth between the tool and twitter to see how a tweet would look and trying to visualise it in my head.

I also wanted it to be mobile-first, and when I was growing up I was always a fan of tumblr being a way for me to see all of my notes and thoughts.

this is where I got the idea of having a deck of tweets, swiping left for deleting them, swiping right for publishing them.

after reading some of the tweets on how the app would function, I ended up getting the idea of a stack view for tweets. 

I really liked this layout, so I decided to go with it.

I also knew that I wanted to make it in a way where I could also use it to schedule tweets for hue to keep it in the same place. I like building for hue first, because I also know that I can get a lot of usage out of it for myself.

the main reason I wanted to build this is because I wanted to have a repo that I could send to people when they asked me to work on projects for them.

I wanted to be able to say that I could build their tweet scheduler for them, and I had some other ideas that would be really useful but I wasn't able to access to the twitter API.

this was a way for me to be able to build something that I could be proud of, and also be able to share with people when they asked me to build the same thing for them.

I still need to add a couple more features to this, but overall I'm really happy with how it's turned out so far.

here's the repo - github.com/sksq96/deck

and here's the deployed version - deck-sksq96s-projects.vercel.app/

the main thing I want to work on is making it clear for people to use hue to help them draft better tweets. I also want to work on this on my phone, being able to swipe through tweets would be great

the one thing that I'm really proud of is being able to get the same view of tweets that I have on twitter. I wanted to keep it simple, but I also wanted to keep it as close to twitter as possible.

I'm really happy with how it's turned out so far, and I'm excited to keep building on it.

the one thing that I wish I could have done better was being able to view what the tweets are going to look like. I was able to build the skeleton of it but I'm not happy with the implementation.

it takes too much effort to manually go and add the images to the tweets. I wanted it to be as simple as possible for me to build the tweet scheduler.

it's probably something that I can improve as I keep working on it; using the X API would help a lot.
