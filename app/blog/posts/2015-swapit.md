Build a website in 5 days? Challenge Accepted!!

Over the course of a 5 day challenge I learnt a lot about building and deploying a website.

I started by creating a wireframe on Balsamiq, syncing with Dropbox and then publishing on Github. Early on I decided to use a 1140 grid CSS to help make the process quicker for me, instead of starting from scratch.

I found a great set of free icons on creative market (which happens to be where my site idea was born from), which helped define the style of my website. I then decided that I wanted to use some scroll CSS to give the website a unique experience.

The first time adding in scroll CSS, I had to re-organise a lot of my code, as I was still learning how to use scroll CSS. I decided I wanted a 3 step slider that was relatively simple, and a header that the user would be able to scroll through. I started with the header, which was far easier, however the slider was a lot more challenging.

Once I had managed to get the scroll CSS in place, I used some jQuery to create the background image slider, which was fun. The javascript was quite simple, and I was able to get it up and running quickly.

As the challenge progressed I started to change my mind about previous design decisions and got stuck on the colour pallete. I decided to go with a darker pallete with a splash of icy blue. I didn't have much experience with colour selection on a website, but this was another thing that I learnt.

The final challenge was to deploy the website live. I had to use my domain, and set my sub-domain to point to the IP provided by Amazon, where I had hosted my site using a Ubuntu instance. I used nginx to deploy my site, and it works great!!
