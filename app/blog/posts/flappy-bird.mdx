The idea is, in any given state of the game, the bird has two actions to choose from, either to flap or not to flap. Q-learning assigns a Q-value for each state-action pair, and the goal is to maximize the total reward. The reward is gained by staying alive, and is lost by crashing the bird or hitting the pipe.

But, what is state in FlappyBird? It can't be just one frame. If it was one frame, it would be impossible to know if the bird is going up or down. We need to know if the bird is going up or down in order to make a better prediction of what action to take. Fortunately, it is possible to use multiple frames to represent the state, and that's exactly what the code does. It uses 4 frames to represent a state.

So the computer just plays the game and learns from it. How does it learn from it? When it crashes the bird or hit the pipe, it gets a negative reward. When it gets a point, it gets a positive reward. That's how it learns to get as many points as possible.

It takes some time for it to learn, and no matter how you train your network, there is always a chance that it crashes the bird. Here is the image-processing helper:

import cv2
import numpy as np

def image_reshape(image_data, prev=None, first=False):
    image_data = cv2.cvtColor(cv2.resize(image_data, (80, 80)), cv2.COLOR_BGR2GRAY)
    _, image_data = cv2.threshold(image_data,1,255,cv2.THRESH_BINARY | cv2.THRESH_OTSU)

    if first:
        return np.stack((image_data, image_data, image_data, image_data), axis=2)
    else:
        image_data = np.reshape(image_data, (80, 80, 1))
        return np.append(image_data, prev[:, :, :3], axis=2)
