## Face Encoder

![aligned face](/writings/face-recognition/aligned.png)

Face recognition is a 3 step process. Detect faces in the image, align faces and represent faces. A face can be represented as a 128-dimension vector. The distance between vectors of two different images of the same person is small, while it is large for two different persons.

To find the location of faces in the image, I used the standard [Viola-Jones](https://www.wikiwand.com/en/Viola%E2%80%93Jones_object_detection_framework) and [HOG](https://www.wikiwand.com/en/Histogram_of_oriented_gradients) based detectors.

In order to align the faces, I used the standard [FaceNet](https://arxiv.org/pdf/1503.03832v1.pdf) procedure of aligning the outer eyes and nose with similar fixed points in a 96x96 crop of the image.

For representing the faces, I used the [OpenFace](https://www.cs.cmu.edu/~satya/docdir/CMU-CS-16-118.pdf) network to actually compute the 128-dimensional representation. The network is trained in a way that the same person is closer to each other in the 128-dimensional space than two different person.

## Clustering

This was the interesting part. Using `DBSCAN` from `sklearn`, I was able to count the number of people in a set of unlabeled images of my friends (I'm leaving out the names, it's my hostel).

## Code

Here's a small snippet of code to encode the faces.

```python
#!/usr/bin/env python2

import cv2
import numpy as np

import dlib

import openface
from model import align, net


imgDim=96
def encode(bgrImg):
	try:
		rgbImg = cv2.cvtColor(bgrImg, cv2.COLOR_BGR2RGB)
		bb = align.getAllFaceBoundingBoxes(rgbImg)
		alignedFaces = [align.align(imgDim, rgbImg, box, landmarkIndices=openface.AlignDlib.OUTER_EYES_AND_NOSE) for box in bb]
		encoding = [net.forward(alignedFace) for alignedFace in alignedFaces]
		return encoding
	except:
		return list()
```

`encode` takes a BGR image (as loaded by `opencv`), converts it to RGB and returns a list of face encodings.
