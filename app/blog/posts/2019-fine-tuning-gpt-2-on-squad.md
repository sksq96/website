# Generating questions using OpenAI's GPT-2

  
I've been working on fine-tuning GPT-2 to generate questions, and was able to come up with a model that produces questions which are better that those generated by the best neural model I've found.

## 1. The results:

The input to my model is a passage and an answer. The model is expected to output a question which results in the given answer, given the passage. The generated question is then evaluated by checking the ranking of the actual answer, when a question answering model is given the passage and the generated question.

The following results are from examples from [SQuAD](https://rajpurkar.github.io/SQuAD-explorer/).

## 2. The code

The code for training the generative model can be found at [github.com/sksq96/mnlp-qgen](https://github.com/sksq96/mnlp-qgen). I am using the huggingface GPT-2 implementation for the model.

## 3. The model

I have used a supervised approach to train the model, using the data from the SQuAD dataset. The model is trained in the following manner:  

**Input to the model:**   
A sample from the SQuAD dataset contains a passage, an actual question and an answer. The model is given a passage and an answer as input. These inputs are separated by a special token. I use (and have arbitrarily chosen) 0 as this special token.  

**Output of the model:**  
The model is expected to output a question, given the passage and answer. The model is trained to output the question as the next sequence, after the sequence `<passage> 0 <answer>`.

The labels for the passage and answer is a sequence of the token 1 (again arbitrary). These tokens are ignored when calculating loss.

The model takes a sequence of 256 tokens as input, and outputs a sequence of 256 tokens. The sequence is expected to be in the following format:

`<passage> 0 <answer> 1 <question> 1 <eos> 1`

*The `<eos>` is a special token which is appended at the end of the question.*

An example, with the special tokens is as follows:

```
The end of the Crusades is traditionally placed at the fall of Acre in 1291, marking the end of Christian crusader presence in the Holy Land. 0 Acre 1 what is considered the end of the Crusades ?<|endoftext|> 1
```

```python
    def train(self):  
       # some code to setup model etc..

        for epoch in range(self.epochs):
            for i, batch in enumerate(tqdm(self.dataloader, desc='Training')):
                self.step += 1
                self.current_epoch = epoch
                batch_size = batch['input_ids'].size(0)

                # put tensors on CUDA
                batch['input_ids'] = batch['input_ids'].cuda()
                batch['labels'] = batch['labels'].cuda()
                batch['attention_mask'] = batch['attention_mask'].cuda()
                batch['lm_labels'] = batch['lm_labels'].cuda()

                # predict and get loss
                outputs = self.model(batch['input_ids'], lm_labels=batch['labels'], attention_mask=batch['attention_mask'])
                loss, logits = outputs[:2]
                loss_value = loss.item()

                # backpropagate
                loss.backward()

                # get accumulated gradients
                grad_norm = 0.0
                for p in self.model.parameters():
                    if p.grad is not None:
                        grad_norm += p.grad.data.norm(2).item() ** 2
                grad_norm = math.sqrt(grad_norm)

                # clip gradients
                if self.args.max_grad_norm > 0:
                    torch.nn.utils.clip_grad_norm_(self.model.parameters(), self.args.max_grad_norm)

                # update weights
                self.optimizer.step()
                self.scheduler.step()

                # validation and logging
                if (self.step + 1) % self.args.validate_every == 0:
                    self.validate(epoch)
                    self.model.train()
```

The model is trained on the dataset using the function `train`, which is seen in the repository under the file `train.py`. The model learns to output a sequence of 256 tokens, given a sequence of 256 tokens. The output is the same as the input, except that the labels are ignored (the labels are used to calculate loss).

### 3.2. Batching

Since the batches are larger than a single example, the data has to be padded to the largest sequence in the batch. The batching and the padding is done in the function `collate_batch` in `utils.py`.

```python
def collate_batch(batch):
    """
    Converts a list of dicts to a dict of tensors. Pads sequences to the largest sequence in the batch.
    """

    # make a list of input_ids
    input_ids = [item['input_ids'] for item in batch]
    # find the length of the largest sequence
    biggest_seq = max([i.size(0) for i in input_ids])

    # new attention mask vector
    attention_mask_new = torch.zeros(len(batch), biggest_seq, dtype=torch.long)
    # new input_ids vector
    input_ids_new = torch.zeros(len(batch), biggest_seq, dtype=torch.long)
    # new labels vector
    labels_new = torch.zeros(len(batch), biggest_seq, dtype=torch.long)

    # loop over each input_id
    for i, sample in enumerate(input_ids):
        # pad input_ids with zeros
        input_ids_new[i][:sample.size(0)] = sample
        # set attention mask to 1 for input_ids
        attention_mask_new[i][:sample.size(0)] = 1 
        # set labels to 1 for input_ids
        labels_new[i][:sample.size(0)] = 1
        # set labels to -1 for padding
        labels_new[i][sample.size(0):] = -1

    # make the tensors
    batch_new = {}
    batch_new['input_ids'] = input_ids_new
    batch_new['labels'] = labels_new
    batch_new['attention_mask'] = attention_mask_new
    batch_new['lm_labels'] = input_ids_new.clone()
    return batch_new
```

The function takes a list of samples, such that each sample is a dict of the form

```python
    {
        'input_ids': [passages, 0, answer, 1, question, 1, eos, 1],
        'labels': [1, 1, 1, 0, question, 0, 1, 1]
    }
```

The function returns a dict of tensors, such that the tensors are padded to the largest sequence in the batch.

The main issue for the model is that there is no clear correct answer for the question. The model is expected to output a question, given a passage and an answer. The model is trained to output the question as the next sequence, after the sequence `<passage> 0 <answer>`.
