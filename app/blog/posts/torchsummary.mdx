After using Keras for a while, I really missed the model.summary() functionality when switching to PyTorch. It's extremely useful for debugging purposes as well as for getting a high-level overview of the architecture in a visual way. I often had to look up layers' output shapes and parameters count while designing CNNs in PyTorch, so I decided to quickly write a small script that prints out a similar summary.

It was supposed to be a quick hack for my own use, but it got quite some interest from developers, so I decided to write a somewhat detailed post about it.

## ~3 minutes introduction to forward hooks in PyTorch

It's really not possible to do this in TensorFlow without running the actual model, so we need to run some data through our PyTorch model to get the actual output shapes of each layer. To do this, we can use forward hooks (for the official docs, see here).

The idea is to register a hook on each layer of the model. Then, you just do a forward pass through the network with a dummy variable of the same size as your training examples. You can then access any intermediate outputs of your network using the hooks.

Here's the code to do so:

```python
# Source: pytorch-summary
summary = OrderedDict()
hooks = []

def register_hook(module):
    def hook(module, input, output):
        class_name = str(module.__class__).split('.')[-1].split("'")[0]
        module_idx = len(summary)

        m_key = '%s-%i' % (class_name, module_idx + 1)
        summary[m_key] = OrderedDict()
        summary[m_key]['input_shape'] = list(input[0].size())
        summary[m_key]['input_shape'][0] = -1
        summary[m_key]['output_shape'] = list(output.data.size())
        summary[m_key]['output_shape'][0] = -1
        summary[m_key]['nb_params'] = get_module_params(module)

    if not isinstance(module, nn.Sequential) and \
        not isinstance(module, nn.ModuleList) and \
        module != model:
        hooks.append(module.register_forward_hook(hook))

# register hook
model.apply(register_hook)
```

What we do here is very simple:

1. register_hook is the function we apply to each layer. It simply takes the current layer and creates a hook that will save the layer's output shape and number of parameters in a dictionary
2. We then apply this function to each layer of the model. Note that hooks are removed at the end of the summary function, so they do not affect the model afterwards.

This is all we need!

### Example

Let's look at an example with a very simple CNN on MNIST, to see what the output looks like:

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from torchsummary import summary

class Net(nn.Module):
    def __init__(self):
        super(Net, self).__init__()
        self.conv1 = nn.Conv2d(1, 32, 3, 1)
        self.conv2 = nn.Conv2d(32, 64, 3, 1)
        self.dropout1 = nn.Dropout2d(0.25)
        self.dropout2 = nn.Dropout2d(0.5)
        self.fc1 = nn.Linear(9216, 128)
        self.fc2 = nn.Linear(128, 10)

    def forward(self, x):
        x = self.conv1(x)
        x = F.relu(x)
        x = self.conv2(x)
        x = F.relu(x)
        x = F.max_pool2d(x, 2)
        x = self.dropout1(x)
        x = torch.flatten(x, 1)
        x = self.fc1(x)
        x = F.relu(x)
        x = self.dropout2(x)
        x = self.fc2(x)
        output = F.log_softmax(x, dim=1)
        return output

model = Net()
summary(model, (1, 28, 28))
```

Here's the output you get!

```text
----------------------------------------------------------------
        Layer (type)               Output Shape         Param #
================================================================
            Conv2d-1           [-1, 32, 26, 26]             320
            Conv2d-2           [-1, 64, 24, 24]          18,496
         Dropout2d-3           [-1, 64, 12, 12]               0
            Linear-4                  [-1, 128]       1,179,776
         Dropout2d-5                  [-1, 128]               0
            Linear-6                   [-1, 10]           1,290
================================================================
Total params: 1,199,882
----------------------------------------------------------------
```
