One of the projects that I was assigned after I joined the team was to design and develop a University Management System. Since we had a few days before the training session, I started thinking about what technologies and languages I should use to best accomplish the task.

And I thought about doing it with PHP, MySQL, and Bootstrap and jQuery UI. I was familiar with PHP and MySQL as I had previously used them together to build both static and dynamic webpages. As for Bootstrap, I had recently learnt about it during a class at university, and I wanted to try using jQuery UI. I figured that using jQuery UI would be the best approach to create a smooth user experience.

After deciding that, I started coding the basic functionalities. I created the required tables in the database and ensured that the PHP scripts were able to query the database and show the results. After I was done with the basic features, I started expanding the project to other features.

I had a lot of fun working on the project as I not only got to use what I already knew but I was also able to learn a lot more. For example, I created the other pages with Bootstrap, which gave them a polished and stylish look. I also used jQuery UI and jQuery to add advanced front-end functionalities like calendars, date pickers, modals, etc.

I worked on this project at the end of 2015, and I will now try to implement some of the work using a different approach.
