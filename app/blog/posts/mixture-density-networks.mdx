A few weeks ago I started re-implementing [World Models](https://arxiv.org/pdf/1803.10122.pdf) in PyTorch. For the RNN part, I realised that I didn't completely understand what a Mixture Density Network was, so I took a week out to try and learn about it.

I thought I'd write a short blog post in case it could be helpful to someone else who is also learning about MDNs.

First, a simple example.

## Data

Let's create a (slightly noisy) sine wave and use it as our training data.

```
x_data = torch.linspace(-10, 10, 1000)
y_data = 7*torch.sin(0.75*x_data) + 0.5*x_data + 3*torch.randn(x_data.size())
```

Now, if we plot y_data against x_data, we get a lovely looking sine wave.

```
plt.figure(figsize=(8, 8))
plt.scatter(x_data, y_data, alpha=0.4)
plt.show()
```


But what happens if we swap x and y, i.e. if we want to predict y given x?

```
# Swap x and y
x_data, y_data = y_data.view(-1, 1), x_data.view(-1, 1)

plt.figure(figsize=(8, 8))
plt.scatter(x_data, y_data, alpha=0.4)
plt.show()
```

The plot now looks like this.


Why did I swap the axis?

In the first plot, given a value on the x-axis, we can try to predict where it will lie on the y-axis. But in the second plot, given a value on the x-axis, there are multiple points on the y-axis.

This is where MDNs come in.

## Simple Neural Network

Let's build a simple neural network and see what happens when we try to predict y given x.

```
n_input, n_hidden, n_output = 1, 20, 1
n_samples = 1000
```

```
model = nn.Sequential(nn.Linear(n_input, n_hidden),
                        nn.Tanh(),
                        nn.Linear(n_hidden, n_output))

loss_fn = nn.MSELoss()

optimizer = torch.optim.RMSprop(model.parameters())

for epoch in range(3000):
    y_pred = model(x_data)
    loss = loss_fn(y_pred, y_data)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    if epoch % 1000 == 0:
        print(loss.data.tolist())
```

```
# Create test data
x_test = torch.linspace(-15, 15, n_samples).view(-1, 1)
y_pred = model(x_test).data

plt.figure(figsize=(8, 8))
plt.scatter(x_data, y_data, alpha=0.4)
plt.scatter(x_test, y_pred, alpha=0.4, color='red')
plt.show()
```


That looks… not great.

It's a bit like drawing a straight line through a complex dataset and hoping for the best.

## Mixture Density Networks

What if instead of trying to predict a single y value, we predict a distribution of y values, given x?

More specifically, what if instead of one Gaussian, we learned a mixture of Gaussians?

For each Gaussian, we can predict 3 things: the mean, the standard deviation and the mixing coefficient (which Gaussian to sample from).

Let's create a Mixture Density Network and see.

```
# Define the MDN
class MDN(nn.Module):
    def __init__(self, n_hidden, n_gaussians):
        super(MDN, self).__init__()
        self.z_h = nn.Sequential(
            nn.Linear(1, n_hidden),
            nn.Tanh()
        )
        self.z_pi = nn.Linear(n_hidden, n_gaussians)
        self.z_mu = nn.Linear(n_hidden, n_gaussians)
        self.z_sigma = nn.Linear(n_hidden, n_gaussians)

    def forward(self, x):
        z_h = self.z_h(x)
        pi = F.softmax(self.z_pi(z_h), -1)
        mu = self.z_mu(z_h)
        sigma = torch.exp(self.z_sigma(z_h))
        return pi, mu, sigma
```

```
# Define the loss
def mdn_loss_fn(y, mu, sigma, pi):
    m = torch.distributions.Normal(loc=mu, scale=sigma)
    loss = torch.exp(m.log_prob(y))
    loss = torch.sum(loss * pi, dim=1)
    loss = -torch.log(loss)
    return torch.mean(loss)
```

```
model = MDN(n_hidden=20, n_gaussians=5)

optimizer = torch.optim.Adam(model.parameters())

# Train the model
for epoch in range(10000):
    pi, mu, sigma = model(x_data)
    loss = mdn_loss_fn(y_data, mu, sigma, pi)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    if epoch % 1000 == 0:
        print(loss.data.tolist())
```

```
# Sample from the model
pi, mu, sigma = model(x_test)

k = torch.multinomial(pi, 1).view(-1)
y_pred = torch.normal(mu, sigma)[np.arange(n_samples), k].data

plt.figure(figsize=(8, 8))
plt.scatter(x_data, y_data, alpha=0.4)
plt.scatter(x_test, y_pred, alpha=0.4, color='red')
plt.show()
```


That is *much* better.

## World Models

Now that we know how MDNs work, let's see how they can be used in World Models.

The authors of the World Models paper used a variational autoencoder (VAE) and an RNN to predict the next frame in a video game.


The VAE is used to compress the input image into a latent vector z. The RNN then takes this latent vector z as input, and predicts the next latent vector z'.

The RNN also predicts whether the next frame will terminate the game (e.g. if the player crashes into a pole in the game).

The authors used a Mixture Density Network as the output layer for the RNN.

Here's my code for the MDN RNN.

```
class MDNRNN(nn.Module):
    def __init__(self, n_hidden, n_gaussians, seq_len, latents):
        super(MDNRNN, self).__init__()
        self.seq_len = seq_len
        self.latents = latents
        self.n_gaussians = n_gaussians

        self.lstm = nn.LSTM(input_size=latents, hidden_size=n_hidden)

        self.z_pi = nn.Linear(n_hidden, n_gaussians * latents)
        self.z_mu = nn.Linear(n_hidden, n_gaussians * latents)
        self.z_sigma = nn.Linear(n_hidden, n_gaussians * latents)
        self.binary_linear = nn.Linear(n_hidden, 1)

    def forward(self, x, hidden):
        output, hidden = self.lstm(x.view(self.seq_len, 1, -1), hidden)
        output = output.view(self.seq_len, -1)

        pi = F.softmax(self.z_pi(output).view(self.seq_len, self.latents, self.n_gaussians), -1)
        mu = self.z_mu(output).view(self.seq_len, self.latents, self.n_gaussians)
        sigma = torch.exp(self.z_sigma(output)).view(self.seq_len, self.latents, self.n_gaussians)

        binary_hat = self.binary_linear(output)
        binary_hat = torch.sigmoid(binary_hat.view(self.seq_len, 1))

        return pi, mu, sigma, binary_hat, hidden
```

```
model = MDNRNN(n_hidden=256, n_gaussians=5, seq_len=seq_len, latents=32)
```
