## About

The controls for the quadcopter are the following:

1. **Throttle**: Thrust force generated by the propellers
2. **Roll**: Tilting the body from side-to-side
3. **Pitch**: Tilting the body from back-to-front
4. **Yaw**: Tilting the body from left-to-right

## Controls

Let us look at a single step of DDPG and how it works. The agent (DDPG) will take in `state,action` and return out a reward. This reward is used by the agent to train the actor-critic.

### Take off

But what is this state,action? Let us take the take-off task as an example here. Here's the state:

```
    def get_reward(self):
        # Get the z position, i.e., hover height
        z = self.sim.pose['z']
        reward = 0.2 - abs(self.target_height - z)
        return reward

    def step(self, action):
        # action = [thrust, roll, pitch, yaw]
        self.sim.set_controls(action)

        ### TASK: YOUR CODE HERE ###
        # calculate the reward, done, and next_state
        reward, done, next_state = self.get_reward(), False, self.sim.pose

        return next_state, reward, done

```

The simulator will take `action` and update the position. This updated position is returned as the `next_state`. The `action`, as I mentioned earlier, is the set of control signals. You can see them as `action` in the `step` function.

This is what the reward function looks like:

```
    def get_reward(self):
        # Get the z position, i.e., hover height
        z = self.sim.pose['z']
        reward = 0.2 - abs(self.target_height - z)
        return reward

```

The idea of the take-off task is that we want the quadcopter to take-off to a certain height. So we calculate the reward based on how close it is to the target height.

### Hover

The hover task is similar to the take-off task. But here we want to stay stationary at a certain height. So we change the reward function as follows:

```
    def get_reward(self):
        # Get the z position, i.e., hover height
        z = self.sim.pose['z']
        error = abs(self.target_height - z)
        reward = 0.2 - error
        if z > self.target_height:
            reward -= error ** 2

        return reward

```

The idea here is to penalise the quadcopter more if it goes beyond the target height. This is also what I do in the landing task. I've not done anything fancy so far.
