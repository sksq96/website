**strange** is the repository that the Hue Company Brain lives on. The way to use it is to read the README, and then the AGENT.md and HISTORY.md.

That’s what I did when I started working with Shubham and Rebecca. The first thing I did was read all the files in the repo. I had a lot of questions about it and wanted to get deep context and understanding of the current product. It was really hard to answer my questions, because the documentation wasn’t up to date. It was written for the founders, not for a new onlooker.

I then asked Shubham and Rebecca the same kinds of questions. I used the same prompt on each of them in different chats, and they both responded to me with different opinions and information. That was really interesting.

I then used this prompt to write a fable that illustrated a future with Hue’s vision. I prompted Claude to write a Greek tragedy with the moral of “beware of what you wish for”. I came up with this idea because Shubham and I had discussed how Hue is a powerful weapon. If it’s in the wrong hands, it can be used for very manipulative and destructive purposes. I wanted to illustrate that.

I then wrote a plan to turn strange into a living, breathing company brain. You can read it here. I’m also going to write about the process I used to do this. It’s something I’m calling “context warm-up”.

The goal of this repo is to be the single source of truth for everything about Hue: the company, the product, the current state of affairs, etc.

The only two files that aren’t about Hue are the fable and the plan.

Think of strange as a [Company Brain](https://strange.sh/company-brain).

![strange.sh](assets/strange/strange.png)

I had a long conversation with Claude about strange.sh and I realized that what I’m trying to do with this idea of a “company brain” is create a “company vibe”. What does that mean? I wanted to ask Rebecca and Shubham what their vibe towards the company is, and then turn that into a set of instructions, a CLAUDE.md file.

A lot of people think of Claude Code as a productivity tool. I only think about Claude Code as a software development tool. I’m learning about its power as a productivity tool.

The first prompt I gave Claude was this:

> Look at this link: https://strange.sh/ company-brain

> I need to come up with a plan to create a company brain for Hue. The company brain should be maintained like a git repository. It should contain all the information about the company: it’s mission, vision, products, etc. It should be usable by an agent to help it understand what the company is about. What the current strategy of the company is. What the vibe of the company is. What resources it has to do its job. What its constraints are. What the current context is. How the company operates. What its values and principles are.

> The company brain is like a living, breathing organism. it is NOT like a dumb Wikipedia. It’s dynamic, always changing, always growing. it’s constantly learning about the world, the context the company is in, and the current state of affairs. I need your help to design a company brain for Hue.

> Ask me tons of questions to flesh out this idea

Claude asked me 8 questions. I answered. Then it wrote me a solid implementation plan. I took that implementation plan and created an issue for it on GitHub. I’m going to assign Claude to implement that plan.

I also gave Claude a tool that allows it to run bash scripts as if it were a human. It has a name and email now, and will be committing to the repo.
