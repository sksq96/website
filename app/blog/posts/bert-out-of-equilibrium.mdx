## Masked language modeling and Markov random fields

In masked language modeling (MLM), we randomly choose some positions in a sentence to replace with the special “mask” token and train a model to predict the correct word at the masked positions. BERT is an implementation of masked language modeling, and, like all MLM models, it predicts words at masked positions conditioned on the unmasked positions.

One way to interpret a model that predicts masked tokens is as a Markov random field (MRF). [Alex Wang and Kyunghyun Cho explored this interpretation](https://arxiv.org/abs/1902.04094). In an MRF, we are given a joint distribution $p(x_1, x_2, \ldots, x_n)$ over all possible sentences $x = (x_1, x_2, \ldots, x_n)$. We can then use this joint distribution to calculate conditional distributions like $p(x_1 | x_2, \ldots, x_n)$, which is the distribution modeled by BERT. Given the joint distribution, we can generate samples from it using Gibbs sampling.

The catch is that defining a joint distribution using BERT’s scores doesn’t mean its conditionals are the distributions BERT predicts. Changing one token also changes the scores for other positions, because those positions see it as input. Those contributions have to be included when computing the conditional.

[Kyunghyun Cho’s correction](https://kyunghyuncho.me/bert-has-a-mouth-and-must-speak-but-it-is-not-an-mrf/) explains this issue and credits our work with Joseph and Ranganath. BERT gives us conditional predictions; the MRF interpretation doesn’t follow automatically.

But we can still use BERT to generate text. It just requires a bit of care.

## Masked language modeling as a generative process

We define a generative process that starts with a sentence with some masked tokens. In each step of the process, we pick a masked token and sample a value for it from BERT’s distribution, conditioned on the rest of the sentence.

For a fixed sampling procedure, this does define a distribution over completed sentences. What we don’t get for free is a joint distribution whose conditionals agree with every prediction BERT makes.

### Sampling from BERT

There are several ways of selecting which masked token to fill in at each step. For a given sentence with k masked tokens, we can choose which one to fill in:

- randomly (with uniform probability)
- by choosing the token with the highest probability of the most probable word (“max prob”)
- by choosing the token with the lowest entropy of its predicted distribution (“min entropy”)

The order that we choose to fill in the tokens can matter. Once a word has been sampled, it becomes context for the next prediction. Different selection rules can therefore give us different distributions over the completed sentence.

## Text infilling

BERT can also fill in discontinuous spans from a sentence. We can mask several words, then use the surrounding text to fill them back in. Sampling from the predicted distribution gives us alternatives instead of always taking the most likely word.

In our [BERT generation project](https://github.com/sksq96/bert-generation), we studied sampling techniques based on these conditional distributions, as well as gender bias in the generated text. The interesting part is that a model trained to fill in blanks can be used to generate text—but the sampling procedure is part of the model we end up with.
